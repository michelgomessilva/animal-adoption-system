# Animal Adoption System

Projeto em andamento para gerenciar processos de adoção de animais, desenvolvido como capstone de um bootcamp em equipe.

O repositório está organizado por stack:

- [`back-end/`](back-end/README.md) — API .NET (ASP.NET Core + EF Core + PostgreSQL). Veja o README do back-end para instruções de setup e execução.
- [`front-end/`](front-end/README.md) — em desenvolvimento por outra equipe.
